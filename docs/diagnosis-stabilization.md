# Busy Bee Helpers - אבחון וייצוב

מסמך עבודה פנימי לאיתור תקלות, ייצוב המערכת והכנת בסיס נקי להמשך פיתוח.

## מטרה

להביא את האפליקציה הקיימת למצב:
- יציב להרצה מקומית
- עקבי בזרימות הליבה
- מוכן לחיבורי תשתית בסיסיים
- נוח להמשך פיתוח ותחזוקה

## היקף השלב

### כן כלול

- סקירה של כל המסכים והזרימות הקיימות
- בדיקת הרשמה, התחברות ואזור אישי
- בדיקת יצירת מטלה, צפייה, עריכה ומחיקה
- בדיקת כפתורים, קישורים וניווט
- בדיקת מובייל ודסקטופ
- זיהוי ותיקון באגים קריטיים
- ניקוי קוד בסיסי וסידור מבנה הפרויקט
- הכנת חיבור מסודר ל-GitHub

### לא כלול בשלב הזה

- בנייה מחדש של המערכת מאפס
- פיצ'רים חדשים
- שינוי עיצובי מלא
- העלאה ל-App Store / Google Play
- חיבורי Backend מתקדמים שלא נדרשים לייצוב

## סדר עבודה מומלץ

### 1. הקמת סביבת עבודה

- לוודא שהפרויקט רץ מקומית בלי שגיאות
- להריץ התקנת תלויות ובדיקת build
- לאתר משתני סביבה חסרים
- לוודא שהקוד מסתנכרן מול GitHub

### 2. מיפוי המערכת

- לזהות את כל המסכים ב-`src/pages`
- לזהות רכיבים משותפים ב-`src/components`
- למפות את זרימות המשתמש הראשיות
- לסמן נקודות תלויות ב-Supabase, מפות, אוטנטיקציה ו-State

### 3. בדיקת זרימות ליבה

- הרשמה
- התחברות
- יציאה מהמערכת
- יצירת מטלה
- צפייה ברשימת מטלות
- צפייה בפרטי מטלה
- צפייה ב-My Tasks / Profile / Admin אם רלוונטי
- ניווט בין המסכים

### 4. בדיקת UI ותצוגה

- התאמה למובייל
- התאמה לדסקטופ
- מרווחים, שבירת שורות, גלילה, overflow
- מצבי טעינה, empty states ושגיאות
- רכיבים חוזרים עם התנהגות עקבית

### 5. בדיקת אינטגרציות

- Supabase client והגדרות אוטנטיקציה
- RLS ופרופילי משתמשים
- מפות
- שליחת/קבלת נתונים

### 6. תיקונים וייצוב

- תיקון שגיאות runtime
- תיקון בעיות טייפים
- תיקון קישורים שבורים
- תיקון תנאים שלא מכסים מצבים אמיתיים
- ניקוי קוד מת
- פיצול לוגיקה בעייתית לפונקציות או קומפוננטות קטנות יותר

## רשימת בדיקות

### אוטנטיקציה

- משתמש חדש יכול להירשם
- משתמש קיים יכול להתחבר
- משתמש יכול להתנתק
- משתמש לא מורשה לא נכנס למסכים מוגנים
- הודעות שגיאה ברורות מוצגות נכון

### מטלות

- יצירת מטלה עובדת
- מטלה נשמרת ומוצגת לאחר רענון
- רשימה נטענת ומסוננת נכון
- פרטי מטלה נפתחים נכון
- פעולות עריכה ומחיקה לא שובשות את המצב

### ניווט

- כל כפתור מוביל ליעד נכון
- אין מסלולים שבורים
- אין לופים או redirect מיותר
- מצב back / forward סביר

### רספונסיביות

- מסכי מובייל לא נשברים
- רכיבים לא חורגים מהרוחב
- הטקסטים לא נחתכים
- הגלילה צפויה

## תקלות נפוצות לחפש

- קריסת קומפוננטה בגלל `undefined`
- קריאות ל-Supabase לפני שהלקוח מוכן
- מצב משתמש שלא נטען בזמן
- מצב טעינה שלא נאכף
- שימוש בנתונים שלא קיימים במבנה הנוכחי
- CSS שמסתמך על רוחב קבוע מדי
- Map / location שלא מתמודד עם ערכים חסרים

## סדר עדיפויות לתיקון

### גבוה

- קריסות מסך
- חוסר יכולת להתחבר או להירשם
- אובדן נתונים
- מסלולים חסומים
- שגיאות שמונעות שימוש בסיסי

### בינוני

- בעיות UI שמפריעות לשימוש
- תגובות לא עקביות של כפתורים
- חוסר אחידות בין מסכים
- בעיות מובייל

### נמוך

- ניקוי קוסמטי
- refactor לא קריטי
- שיפורי naming
- ארגון קבצים

## פלט צפוי בסיום השלב

- אפליקציה שרצה בלי שגיאות קריטיות
- רשימת באגים מתועדת
- רשימת תיקונים שבוצעו
- נקודות סיכון שנשארו להמשך
- בסיס קוד מסודר יותר להמשך עבודה

## Definition of Done

- כל הזרימות המרכזיות נבדקו
- תקלות קריטיות טופלו
- אין שגיאות blocking בהרצה רגילה
- הניווט והאוטנטיקציה יציבים
- המבנה מספיק נקי להמשך פיתוח
