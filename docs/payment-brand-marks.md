# Payment brand marks

Original artwork, used to identify supported payment methods in the method selector.
These are brand marks, not generic icons or a representation of an open-source license.
The separate continue button opens the hosted Cardcom checkout.

- `apple-pay.svg`: original SVG from https://developer.apple.com/apple-pay/marketing/Apple-Pay-Mark.zip
  Guidelines: https://developer.apple.com/apple-pay/marketing/
- `google-pay.png`: original acceptance mark from https://developers.google.com/static/pay/api/images/brand-guidelines/google-pay-mark.png
  Guidelines: https://developers.google.com/pay/api/web/guides/brand-guidelines
- `bit.svg`: original SVG displayed by Cardcom at https://www.cardcom.solutions/assets/power-strip/bit.svg
  Provider example: https://www.cardcom.solutions/

Artwork is stored locally and its colors, paths, and aspect ratios are preserved.
