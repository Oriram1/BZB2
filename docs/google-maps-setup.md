# תיעוד Google Maps

## מה הוגדר

הוגדר פרויקט Google Cloud ייעודי עבור האפליקציה:

- שם הפרויקט: `BusyBee Maps`
- מזהה הפרויקט: `fast-oxide-503716-r0`
- חשבון חיוב: `My Billing Account`
- המפתח הוגדר ללא הגבלת דומיין, בהתאם לדרישה הנוכחית.

## שירותים שהופעלו

בפרויקט הופעלו השירותים הבאים:

- `Maps JavaScript API` להצגת מפות בתוך האתר.
- `Geocoding API` להמרת טקסט כמו `עין השופט` לקואורדינטות.

המפתח `BusyBee Web Maps` מוגבל לשני השירותים האלה בלבד. אין במסמך הזה את ערך המפתח עצמו.

## חיוב

הפרויקט חובר לחשבון החיוב הקיים. חיבור חיוב נדרש כדי ש־Google תאפשר שימוש מלא בשירותי המפות וה־Geocoding.

הפרויקטים האחרים שנבדקו בחשבון החיוב נותקו לפי ההחלטה שניתנה, למעט `Coupon Master`. `itzik` נשאר מחובר לחשבון חיוב נפרד.

## משתני סביבה

בקובץ `.env` המקומי נוסף:

```env
VITE_GOOGLE_MAPS_API_KEY="..."
```

המפתח לא אמור להישמר ב־Git, במסמכי תיעוד או בצילומי מסך. קובץ `.env.example` מכיל רק ערך ריק לדוגמה.

## שינויים בקוד

### טעינת Google Maps

ב־`src/components/tasks/GoogleMapsProvider.tsx`:

- נטענת ספריית Google Maps באמצעות `@googlemaps/js-api-loader`.
- קיימת הודעת שגיאה אם חסר מפתח, אם השירות לא נטען או אם אין הרשאות/חיוב.
- הספק משמש את רכיבי המפה באפליקציה.

### בחירת מיקום בעת פרסום מטלה

ב־`src/components/tasks/GoogleMapPicker.tsx` קיימת מפה לבחירת נקודה בעת יצירת מטלה. בעת שמירת מטלה נשמרים:

- `location` כטקסט שהוזן.
- `latitude`.
- `longitude`.

### מפה במסך פרטי משימה

נוסף הרכיב `src/components/tasks/TaskLocationMap.tsx`:

1. אם קיימות קואורדינטות, מוצגת מפה מוטמעת עם סמן.
2. אם קיימת רק כתובת, מופעל `Geocoder` של Google Maps.
3. לאחר זיהוי הכתובת, המפה מוצגת בתוך האתר עם הסמן המתאים.
4. אם הזיהוי נכשל, מוצגת הודעה וקישור fallback ל־Google Maps.

הרכיב שולב במסך `src/pages/TaskDetail.tsx`.

## התקלה שאותרה ותוקנה

בהתחלה המסך הציג fallback עם ההודעה שלא נמצא מיקום. בדיקת Console הראתה:

- `Geocoding Service: This API is not activated on your API project`.
- לאחר הפעלת השירות התקבלה שגיאת הרשאה, מפני שהמפתח היה מוגבל רק ל־`Maps JavaScript API`.

לאחר הפעלת `Geocoding API` והוספתו להרשאות המפתח, הבדיקה הצליחה.

## בדיקה סופית

נבדקה מטלה עם המיקום `עין השופט`:

- Google Maps נטען.
- הטקסט הומר לקואורדינטות.
- נמצאה נקודת המפה.
- המפה הוצגה בתוך מסך פרטי המטלה.
- המפה הכילה סמן באזור עין השופט.

בנוסף, `npm run build` עבר בהצלחה לאחר השינויים.

## תחזוקה והמשך עבודה

- מטלות חדשות שומרות קואורדינטות ישירות מבחירת המשתמש במפה.
- מטלות ישנות עם כתובת בלבד משתמשות ב־Geocoding בעת פתיחת מסך הפרטים.
- אין להכניס את מפתח ה־API ל־Git.
- מומלץ בעתיד להוסיף הגבלת דומיינים לאחר שיהיה דומיין production קבוע.
- מומלץ לעבור בהמשך מ־`google.maps.Marker` ל־`AdvancedMarkerElement`, מאחר ש־Google מסמנת את `Marker` כ־deprecated.
